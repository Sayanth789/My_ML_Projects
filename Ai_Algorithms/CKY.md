```**function**  CKY-PARSE(words, grammar) **returns** table 
  **for** j <- **from** 1 **to** LENGTH(words) **do** 
      **for all** {A| A -> words[j] ∈ grammar}
          table[j - 1, j] <- table[j - 1, j] U A
        **for**  i <- **from** j - 1 **down to** 0 **do** 
            **for** k <- i + 1 **to** j - 1 **do** 
                **for all** {A| A -> BC ∈ grammar **and** B ∈ table[i, k] **and** C ∈ table[k, j]}
                     table[i, j] <- table [i, j] U A
```
 The CKY algorithm is a dynamic programming parsing algorithm used in Natural Language Processing (NLP) 
to determine whether a sentence can be generated by a given context-free grammar (CFG) and to build its parse tree.
### Used in 
`Syntax Parsing in NLP`

 * Used to parse sentences and determine their grammatical structure

 * Produces parse trees (constituency trees)

CKY helps decide how words group into:

> noun phrases (NP)

> verb phrases (VP)

> sentence (S)
Compiler Design (theoretical use), Parsing programming languages defined by CFGs.Mostly educational/theoretical in compilers (LL/LR parsers are more common in practice)

Why CKY matters

* Clean mathematical formulation
* Easy to extend to probabilistic models
* Foundation for many modern parsing ideas
