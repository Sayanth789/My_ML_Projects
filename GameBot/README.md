#### A Python made TicTacToe agent trained with Q-Learning . The agent leans by playing games , receiving rewards
#### for wns(+1) , penalties for losses (-1), and 0 for draws. This project is modular, GitHub-ready, and easy to extend.

## Note: This is just for a demonstration purpose and for fun 🌹 🖤. I look into dive deeper and making a robo 
### that can reach and reserach 🪐  ... 👀 🫢

## Features
- Tic-Tac-Toe environment class (`TicTacToeEnv`)
- Q-Learning agent (`QLearningAgent`) with:
  - Q-table saving/loading
  - Exploration-exploitation (epsilon-greedy)
- Trainer module to run thousands of episodes
- Example scripts for training and testing
- Modular structure for easy extension
