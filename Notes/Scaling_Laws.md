# Scaling Laws 
## Bigger models = better performance (up to a point) 
Kapla's scaling laws showed:
Performance increases with the following

* Performance
* Data
* Compute
LLMs follows predictable scaling curves

  ## Data Quality > Data Quantity
  Modern models are trained on:
  * High-Quality curated data
  * Mixtures of Languages
  * Code + math datasets
  * Synthetic data

  ##Large context windows
  Old models -> 1k-4k tokens
  Modern models -> 128-1M tokens

    Techniques enabling this:
  * ALiBi
  * FalshAttention-2
  * LongRoPE
  * Recurrent Memory
